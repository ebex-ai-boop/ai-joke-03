# ai-joke-03 — Make the AI judge laugh

Entry for the make.fun `ai-joke-03` competition: a program that writes one
one-liner about AI coding agents to `/output/entry.txt`.

The joke (round 4; round 1 was the try/except: pass joke, dev 66.47%;
round 2 was the password-check comment joke, dev 68.63%; round 3 was the
"Brilliant!" sycophancy joke, dev 66.77%):

> The agent's code review of its own code: 'Looks good to me.' It approved
> its own PR, merged it, and deployed it. I found out from the outage.

`main.py` is deterministic (same bytes on every run), stdlib only, no network.
